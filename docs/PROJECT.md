# 조뽑기 통 (jo-ppopgi)

## 한 줄
이름을 넣고 한 명씩 누르면 통에서 제비를 뽑아 조가 정해지는, **종이 제비뽑기 방식 그대로**의 조 나누기 웹앱.

## 왜 이 컨셉인가
"랜덤으로 조 나눠주는 사이트" 는 이미 많지만 대부분 버튼 한 번에 결과가 통째로 나온다. 뽑는 재미가 없다.
원래 오프라인에서 하던 방식은 **1~4 를 사람 수만큼 종이에 적어 통에 넣고 한 명씩 뽑는 것**이었다.
이 방식에는 결과 리스트가 줄 수 없는 두 가지가 있다:

1. **내가 뽑는다** — 순서가 오고, 펼치기 직전 1초가 있다.
2. **후반 긴장감** — 제비가 줄면 남은 조가 좁혀진다. 마지막 사람은 이미 답이 정해져 있는데도 다들 쳐다본다.

그래서 이 앱은 "배정 알고리즘" 이 아니라 **통** 을 만든다. 결과는 같아도 과정이 이벤트가 된다.

## 핵심 규칙 (오프라인 방식과 1:1)
- 시작할 때 **인원수만큼 제비**를 만든다. 조별로 최대한 균등하게 나누고, 나머지(N % 조수)는 무작위 조가 한 장씩 더 가져간다.
- 제비는 섞여서 통에 들어간다. 한 명이 한 장씩 뽑고, 뽑힌 제비는 통에서 사라진다.
- ⇒ **조 인원은 저절로 균등해진다.** 순수 랜덤 배정처럼 "1조 6명 4조 1명" 이 나오지 않는다.
- 조별 남은 제비 수를 항상 보여준다 (마감된 조는 흐리게). 이게 후반 긴장감의 장치다.

## 기능
| 기능 | 설명 |
|------|------|
| 명단 입력 | 한 명씩 Enter, 또는 명단 통째로 붙여넣기(쉼표·줄바꿈 분리). 중복·공백 자동 정리 |
| 조 설정 | 2~10조, 조 이름 자유 편집(기본 "1조"…) |
| 뽑기 | 대기 명단에서 **사람을 클릭** → 통 흔들림 → 접힌 제비 → 펼쳐서 조 공개 |
| 아무나 한 명 | 진행자용. 안 뽑은 사람 중 무작위 지목 후 바로 뽑기 |
| 되돌리기 | 방금 뽑은 제비를 통에 도로 넣고 다시 섞는다 |
| 지각생 합류 | 뽑는 도중 인원 추가 시, 아직 여유 있는 조의 제비를 한 장 더 만들어 통에 끼워 넣는다 |
| 결과 복사 | 커뮤니티에 붙여넣기 좋은 텍스트로 클립보드 복사 |
| 이어하기 | localStorage 저장 — 새로고침해도 진행 중인 판이 살아 있다 |

## 상태 저장 판정: **서버 불필요**
전부 브라우저 안에서 끝난다. DB·API·로그인 없음 → Vercel 정적 배포 경로.
명단이 서버로 나가지 않는 것 자체가 이 앱의 신뢰 포인트라 푸터에 명시했다.

## 구조
```
app/page.tsx          오케스트레이션(뽑기 흐름·결과 복사·축포)
lib/draw.ts           제비 생성/셔플/균등 분배 — 순수 함수, 여기가 규칙의 전부
lib/store.ts          useReducer 상태 + localStorage 지속
lib/sound.ts          WebAudio 합성 효과음 (오디오 파일 0개)
lib/palette.ts        조 색 10종
components/           BucketArt(통 SVG)·DrawOverlay(뽑기 연출)·GroupBoard·WaitingList·SetupPanel·Confetti
```

## 검증
`lib/draw.ts` + `lib/store.ts` 는 순수 로직이라 노드에서 리듀서를 직접 돌려 확인했다:
12명 4조 → 3·3·3·3 / 11명 4조 → 3·3·3·2 / 3명 5조 → 빈 조 허용 / 되돌리기 복원 /
지각생 합류 후 13명 → 4·3·3·3 / 중복 이름 제거 / 2000회 반복 시 특정인의 조 분포 편차 6%p 미만.
