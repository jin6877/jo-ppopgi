# 조뽑기 통 (jo-ppopgi)

종이에 **1, 2, 3, 4…** 를 사람 수만큼 적어 통에 넣고 한 명씩 뽑던 그 방식을 그대로 옮긴 조 나누기 웹앱.

- 이름을 넣고 **사람을 클릭**하면 통이 흔들리고, 접힌 제비가 나와, 펼쳐지면서 조가 공개된다.
- 제비를 인원수만큼 만들어 넣기 때문에 **조 인원이 저절로 균등**해진다. (순수 랜덤 배정과 다른 점)
- 조별 남은 제비가 보여서 후반으로 갈수록 긴장감이 붙는다.
- 명단은 서버로 나가지 않는다. 계산도 저장도 전부 브라우저 안에서.

기획·규칙 정리는 [docs/PROJECT.md](docs/PROJECT.md).

## 개발
```bash
npm install
npm run dev      # http://localhost:3000
```

## 배포
side-app 작업공간에서: `bash scripts/deploy.sh jo-ppopgi`
